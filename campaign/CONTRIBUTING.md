# Contributing

The most valuable contribution to this repository is **a correction with a source attached.**

## Ways to help, roughly in order of value

1. **Break a claim.** Find a number, date, attribution, or evidence-tier error and correct it. Include
   the retrieved source. Corrections are logged, not quietly merged.
2. **Add a missing negative result.** Failed and discontinued programs are the least-recorded and most
   research-relevant part of this literature.
3. **Review a domain file as a named expert.** Sign it. Disagreement on the record is the point — see
   workstream W3 in [CAMPAIGN.md](CAMPAIGN.md).
4. **Sharpen a barrier into an experiment.** Take an entry from the synthesis document's barrier list and
   specify the decisive experiment, its readout, and what would falsify the hypothesis.
5. **Add a domain or a subfield that is genuinely missing** — with the same research → audit discipline.

## Rules for any content change

- Every factual claim carries a real, retrieved citation: authors/group, title, source, year, and an
  identifier (PMID / DOI / NCT / URL).
- **Never add a citation you have not personally retrieved.** This is the one unforgivable error here.
  If you cannot retrieve it, mark the claim `[unverified]` or leave it out.
- Efficacy numbers include trial, cohort, N, and endpoint definition.
- State the evidence tier: approved / phase 3 positive / phase 1–2 signal / preclinical / hypothesis.
- Do not upgrade a secondary source into a primary one. Cite the press release as a press release.
- Do not soften negative results.
- If your change makes a file longer without making a research or clinical decision clearer, reconsider it.

## Pull requests

- One domain or one theme per PR. Large mixed PRs are hard to audit and audit is the whole value proposition.
- In the PR description, say which claims you verified and how.
- Corrections to previously-published claims should also be noted in [AUDIT-LOG.md](AUDIT-LOG.md).

## Tone

Be direct about uncertainty. "The evidence does not establish this" is a complete and welcome sentence.
Confidence that outruns the evidence is the specific failure mode this project is organized against.
